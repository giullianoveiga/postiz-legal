Política de Privacidade

Última atualização: 12/11/2026

Esta política descreve como o Postiz FabricaDigital (postiz.fabricadigital.online) trata dados.

Dados que acessamos

Ao conectar uma conta do Google/YouTube ou do TikTok, recebemos do provedor: nome e foto do perfil, identificador da conta e tokens de acesso. Usamos esses dados apenas para autenticar a conexão, listar o canal e publicar ou agendar o conteúdo que o próprio usuário criar.

Uso dos dados do Google

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Armazenamento e compartilhamento

Os dados ficam em servidor controlado pela FabricaDigital. Não vendemos nem compartilhamos dados com terceiros, exceto com a própria plataforma (YouTube ou TikTok) para executar as publicações solicitadas.

Exclusão e revogação

O usuário pode remover o canal no painel do serviço, o que apaga os tokens armazenados, e revogar o acesso em myaccount.google.com/permissions ou nas configurações do TikTok. Para solicitar a exclusão de qualquer dado, use o site postiz.fabricadigital.online.
